# Booker Sales & Payment Tracking System

A Progressive Web App (PWA) designed for real-time tracking of booker sales, deposits, and payment reconciliations.

## Tech Stack
- **Framework:** Next.js 14 (App Router, TypeScript)
- **Styling:** Tailwind CSS, shadcn/ui
- **Database & Auth:** Supabase (`@supabase/supabase-js`, `@supabase/ssr`)
- **Offline / PWA Support:** `@ducanh2912/next-pwa`
- **Analytics:** Recharts
- **Hosting:** Vercel

## Project Structure
The repository is fully scaffolded and ready for development. See the folder layout as structured in Phase 1.

## Development

To run the local development server:
```bash
npm run dev
```
